# Paulo Braai XL

Interactive 3D concept of an extended, lidded version of the Paulo braai.

Live viewer: https://kkonkobo.github.io/paulo-braai-xl/

- `src/model.js` builds the model (dimensions in mm, in the `DIM` table at the top)
- `node build.mjs` bundles the viewer into `docs/index.html`
- `node export-glb.mjs` writes the `.glb` files in `docs/`
